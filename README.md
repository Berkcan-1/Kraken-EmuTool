# Kraken EmuTool

## An advanced emulator client that communicates with Android Studio via Scrcpy.

In short, the program offers an enhanced experience by adding EDL Fastboot Recovery partitions to the emulator based on Android Studio. 

The program allows you to quickly uninstall applications from user 0. A bootloader lock system has been implemented. If the `fastboot oem unlock` command is sent, the phone will wipe data and start up as writable. Additionally, 3D hardware removal and testpointing capabilities are available. It's a lifesaver in bootloop situations.

## How to Use?

Download the application as a zip file. Then open it and create an AVD. And you can enter it. You can turn it on with the power button.  <img width="1905" height="842" alt="image" src="https://github.com/user-attachments/assets/240ad519-70cf-49d0-ac81-bea142ab3fa7" />


## Why should I use it?

This is especially for people who are afraid to test on their own devices for fear of hard bricking real phones, or for those who are tired of the tedious nature of emulators.

## Requirements

- Android Studio

- Commandline-tools

- Android Studio Emulator
